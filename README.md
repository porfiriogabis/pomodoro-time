# Tomate Foco

Um cronômetro Pomodoro simples para estudar e trabalhar com mais foco. Feito só com HTML, CSS e JavaScript, sem instalar nada.

## O que é o Pomodoro?

Você trabalha 25 minutos sem distração (um "tomate"), faz uma pausa de 5 minutos e repete. A cada 4 tomates, uma pausa longa de 15 minutos.

## Como usar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Escreva no que vai focar e clique em **Iniciar**.

## Recursos

- Três modos: foco, pausa curta e pausa longa
- Círculo de progresso que esvazia conforme o tempo passa
- Tempo visível no título da aba, para acompanhar com outra aba aberta
- Aviso sonoro ao terminar
- Contador de tomates do dia, salvo no navegador

## O que você aprende

- Temporizadores com `setInterval` e `clearInterval`
- Salvar dados com `localStorage`
- Animar um círculo com SVG e CSS
- Gerar som com a Web Audio API
